# academicService

Microservicio académico de la plataforma Libro Digital.

Gestiona cursos, asignaturas, matrículas, evaluaciones y calificaciones. Desarrollado con Spring Boot 4.0.5, Java 21 y Maven. Forma parte de una arquitectura de microservicios desacoplados para la gestión académica de colegios.

## Stack tecnológico
- Java 21
- Spring Boot 4.0.5
- Spring Web
- Spring Data JPA
- Spring Security
- Maven
- PostgreSQL

## Instalación y ejecución
1. Clona este repositorio.
2. Configura la conexión a la base de datos en `src/main/resources/application.properties`.
3. Compila y ejecuta con:
   ```sh
   mvn clean spring-boot:run
   ```
